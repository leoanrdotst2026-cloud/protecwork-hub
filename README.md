# Protecwork Hub

Gestão Comercial, Orçamentos e Oportunidades — SST e Sites.

## Publicar online (GitHub Pages)

1. Faça upload do arquivo completo como `index.html` (substitua o placeholder atual):
   - Abra o repositório → **Add file** → **Upload files**
   - Arraste o HTML do Protecwork Hub e nomeie como `index.html`
2. Vá em **Settings** → **Pages**
3. Em **Source**, escolha **Deploy from a branch**
4. Branch: **main** / pasta: **/ (root)** → **Save**

Em cerca de 1 minuto o site estará em:

**https://leoanrdotst2026-cloud.github.io/protecwork-hub/**

## Uso local

Abra o `index.html` no navegador. Dados ficam no localStorage. Backup em Configurações.
